Vision-Based Robotic Hand

Custom-designed and 3D-printed robotic hand with 5-joint articulation that tracks and replicates human hand gestures in real time. Uses MediaPipe for hand landmark detection (21 keypoints at 60 FPS), Python gesture-to-servo mapping via inverse kinematics, and UART serial communication to Arduino. Handles hand rotation, scale variation, and partial occlusion gracefully.

Autonomous Disinfectant Robot

Hospital-grade autonomous mobile platform for UV-C-based surface and air disinfection. Eliminates manual staff exposure to contaminated areas. Features SLAM-based navigation (LiDAR mapping + localization), ultrasonic + LiDAR collision avoidance, configurable UV-C light control with timers, and mobile app interface for nurses to dispatch robot to specific rooms via uploaded hospital floor maps. ESP32 + Arduino real-time I/O at 100ms cycle.
